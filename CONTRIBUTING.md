# Contributing Guidelines

Thank you for your interest in contributing to projects under [@OxDurgeshxO](https://github.com/OxDurgeshxO)!

## Development Workflow
1. **Fork & Branch**: Create a feature branch from `main` using descriptive naming:
   - `feat/feature-name`
   - `fix/bug-description`
   - `perf/optimization`
2. **Coding Standards**:
   - Write clean, modular, and type-safe code (TypeScript / Modern Python).
   - Ensure all automated tests and linter checks pass locally prior to submitting.
3. **Commit Conventions**:
   Follow [Conventional Commits](https://www.conventionalcommits.org/):
   - `feat(...)`: New feature
   - `fix(...)`: Bug fix
   - `perf(...)`: Performance improvement
   - `ci(...)`: Workflow or CI configuration
   - `docs(...)`: Documentation updates

## Pull Request Checklist
- [ ] Code passes all local linting and test suites.
- [ ] PR description clearly explains the changes and rationale.
- [ ] No extraneous debug statements, temporary files, or secrets committed.
