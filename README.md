# .github

This repository defines account-wide community health files, security disclosure standards, and contribution guidelines for all public projects maintained under [@OxDurgeshxO](https://github.com/OxDurgeshxO).

## Included Standards
- **[SECURITY.md](./SECURITY.md)**: Responsible vulnerability disclosure policy and severity definitions.
- **[CONTRIBUTING.md](./CONTRIBUTING.md)**: Coding conventions, PR workflow, and verification guidelines.
- **[CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md)**: Contributor Covenant Code of Conduct v2.1.
- **Issue & PR Templates**: Automated issue forms and verification checklist templates across all repositories.
